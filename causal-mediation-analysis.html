    How this was made

    Papers were gathered on 25 October 2026 by 6 parallel web-search passes (identification and assumptions; multiple, path-specific and longitudinal mediators; high-dimensional and omics mediators; estimation and inference; applied fields and software; mediation in machine learning and NLP). Web search was rate-limited, so each pass also harvested papers from the reference lists of surveys, key papers, author pages and curated reading lists it found, drawing on arXiv, OpenReview, journals, proceedings and the ML Anthology. The passes returned 1,372 entries; after merging duplicate titles, 880 papers remained. Each paper's title (weighted twice) and a short paraphrased summary were turned into TF-IDF vectors with unigrams and bigrams, reduced to 100 dimensions with LSA, and grouped with k-means. k = 20 gave the best cosine silhouette between 8 and 20. Keywords come from class-based TF-IDF; topic names were written by reading each cluster's keywords and member titles. The map is a UMAP projection of the same vectors, lightly guided by the cluster labels so each topic reads as one region; distances between regions are approximate. Summaries are paraphrases, some written from titles or citing papers rather than the original abstract, and some entries found only in reference lists have no link. The collection is broad but not exhaustive. Some neighbouring work (recommender debiasing, causal fairness, language-model interpretability) appears because it borrows mediation ideas. Papers by Yuta Kawakami were added by hand on request afterwards; each was placed in its closest topic and next to its most similar papers on the map.
