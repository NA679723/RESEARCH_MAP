    How this was made

    Papers were gathered on 25 October 2026 by 5 parallel web-search passes (Rosenbaum-style and E-value methods; regression and econometric sensitivity analysis; marginal sensitivity models and machine learning; sensitivity for mediation, missing data and trials; quantitative bias analysis and practice). Web search was rate-limited, so each pass also harvested papers from the reference lists of surveys, key papers, author pages and curated reading lists it found, drawing on arXiv, OpenReview, journals, proceedings and the ML Anthology. The passes returned 1,483 entries; after merging duplicate titles, 1,067 papers remained. Each paper's title (weighted twice) and a short paraphrased summary were turned into TF-IDF vectors with unigrams and bigrams, reduced to 100 dimensions with LSA, and grouped with k-means. k = 20 gave the best cosine silhouette between 8 and 20. Keywords come from class-based TF-IDF; topic names were written by reading each cluster's keywords and member titles. The map is a UMAP projection of the same vectors, lightly guided by the cluster labels so each topic reads as one region; distances between regions are approximate. Summaries are paraphrases, some written from titles or citing papers rather than the original abstract, and some entries found only in reference lists have no link. The collection is broad but not exhaustive. The map covers sensitivity analysis for causal assumptions (unmeasured confounding, missing data, other violated assumptions), not global sensitivity analysis of simulation models.
