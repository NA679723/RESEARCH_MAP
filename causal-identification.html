    How this was made

    Papers were gathered on 25 October 2026 by 5 parallel web-search passes (graphical identification and adjustment; transportability, data fusion and selection bias; econometric identification strategies; counterfactual, proxy and structural-equation identification; identification meets machine learning and estimation). Web search was rate-limited, so each pass also harvested papers from the reference lists of surveys, key papers, author pages and curated reading lists it found, drawing on arXiv, OpenReview, journals, proceedings and the ML Anthology. The passes returned 2,399 entries; after merging duplicate titles, 1,683 papers remained. Each paper's title (weighted twice) and a short paraphrased summary were turned into TF-IDF vectors with unigrams and bigrams, reduced to 100 dimensions with LSA, and grouped with k-means. k = 20 gave the best cosine silhouette between 8 and 20. Keywords come from class-based TF-IDF; topic names were written by reading each cluster's keywords and member titles. The map is a UMAP projection of the same vectors, lightly guided by the cluster labels so each topic reads as one region; distances between regions are approximate. Summaries are paraphrases, some written from titles or citing papers rather than the original abstract, and some entries found only in reference lists have no link. The collection is broad but not exhaustive. Identification is a step in almost every causal analysis, so this map focuses on work about identification itself and includes some estimation papers that come with identification results. Papers by Yuta Kawakami that the searches did not pick up were added by hand on request afterwards; each was placed in its closest topic and next to its most similar papers on the map.
