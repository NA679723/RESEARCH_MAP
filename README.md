# CRL_MAP

Interactive literature maps. Each page is a single self-contained HTML file (no build step), served with GitHub Pages.

| Page | Live link |
|---|---|
| **Causal Representation Learning Atlas** — 703 papers in 20 research themes | https://na679723.github.io/CRL_MAP/ |
| **Fairness in ML Topic Map** — 1,751 fairness and bias papers (2014–2026) in six themes | https://na679723.github.io/CRL_MAP/topic_map.html |

Hover a point to see the paper. On the atlas, click a topic to isolate it and search the full reading list.
